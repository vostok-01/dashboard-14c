# dashboard-14c

Tableau de bord de suivi de finances personnelles, dans un seul fichier HTML (`index.html`). Il s'exécute entièrement dans le navigateur : aucune installation, aucun serveur.

Il est publié sur GitHub Pages à l'adresse https://vostok-01.github.io/dashboard-14c/ et protégé par un mot de passe (StaticCrypt).

Il sert à visualiser ses comptes et ses dépenses à partir d'un export Excel : synthèse mensuelle, répartition par catégorie, suivi du budget et liste détaillée des transactions.

## Utilisation

Ouvre ce fichier dans Chrome, Edge ou Firefox (version récente).

1. Glisse ton Excel n’importe où sur la page, ou utilise la zone d’import de l’onglet Données. Les fichiers .xlsx et .csv sont acceptés.
2. Formats reconnus : le classeur Transactions (Date, Type, Catégorie, Sous-catégorie, Montant, Libellé) et l’ancien Budget tracking de TABLEUR COMPTE.
3. Les lignes illisibles ne sont pas comptées : elles sont listées dans Données → Qualité des données, avec leur numéro de ligne Excel.
